# Computational Mathematics with Maple

A collection of Maple worksheets from computational mathematics coursework, including numerical and symbolic mathematics exercises, homework, reviews, a MAD4471 project, Maple fundamentals, and cryptography-themed worksheets.

> **Portfolio status:** This is an organizational starter. Worksheet files are the original, unmodified uploads. Worksheet contents and authorship have **not** been fully audited, and the code has **not** been executed or validated in Maple. Review before making this repository public.

## Repository layout

- `Projects/MAD4471/` — `MAD4471 Project.mw`; document the methods, goals and outputs after reviewing the worksheet.
- `Coursework/Homework/` — homework worksheets from lectures 1–6.
- `Coursework/Maple-Fundamentals/` — basic functions, string functions, and an October 12 session worksheet (authorship and context to verify).
- `Topics/Cryptography/` — worksheets named for Pollard rho, RSA signatures, and ElGamal; these are topic labels, not a claim that the implementations are verified or production-safe.
- `Coursework/Review/` — review-question worksheets.
- `Reference-Materials/Lectures/` — `SCM-ln...` files; potentially instructor-provided material.
- `Reference-Materials/Reviews-and-Solutions/` — `SCM-revq...` worksheets and test solutions; potentially instructor-provided material.

## File formats and opening the worksheets

- `.mw`: Maple worksheet format.
- `.mws`: Classic Maple worksheet format. Compatibility/conversion varies by installed Maple version.

Open the worksheets with **Maple**. GitHub is a storage and version-control platform; it does not run Maple worksheets. For readable source on GitHub, consider exporting your own Maple commands as `.mpl` plaintext files, keeping the original worksheets as supporting artifacts. Check that exported scripts run correctly before publishing.
