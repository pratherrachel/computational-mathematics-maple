# Computational Mathematics with Maple

Readable Maple code examples and coursework exploring symbolic computation, number theory, modular arithmetic, and introductory cryptography.

## Start here

GitHub can display the **`.mpl` text files** directly. Those are the easiest files to browse. The supplied `.mw` and `.mws` worksheets are retained separately in `Original-Worksheets/` for use in Maple, after a text-based name-redaction pass.

| Folder | Contents |
| --- | --- |
| `Topics/Cryptography/` | Readable RSA signatures, Pollard rho, and ElGamal examples |
| `Coursework` | Arithmetic, procedures, strings, bits, modular operations, selected review and homework text transcriptions |
| `Projects/MAD4471/` | Integer factorization and RSA-related project calculations |

## Important qualifications

- The `.mpl` scripts are **transcriptions**, not validated upgrades or tested improvements. Some worksheets include incomplete or exploratory commands.
- Small cryptographic parameters are only educational examples, **not secure cryptography**.

## Running code

Open Maple and read or execute an individual `.mpl` script. The native worksheet formats require Maple (and older `.mws` files may require conversion).
