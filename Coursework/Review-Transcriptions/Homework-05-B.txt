    J(n) = 2*J(n/2) - 1          if n > 1 and n is even
    J(n) = 2*J((n-1)/2) + 1   if  n > 1 and n is odd

(i) Write a recursive procedure to compute J. [As a check the first 16 values (starting with 1) of J(n) are 1,1,3,1,3,5,7,1,3,5,7,9,11,13,15,1]. 
(ii)Compute the value of J(10000). 
(iii) Can you explain why this is so much faster than our recursive procedure to compute the n-th Fibonacci number?
J:=proc(n)
local i, even, odd, Sol;
if n=1 then
  return n;
end if;
even:=0;
odd:=0;
for i from 1 to n do
  if type(i, even)=true then
    even:=(2*(i/2))-1;
    Sol:=even;
  else 
    odd:=(2*((i-1)/2))+1;
    Sol:=odd
  end if;
end do;
 even; odd;
end proc:

Problem 4.  

Happy numbers are positive integers which end up at 1 under iteration of the "sum of squares of digits map". That is, if one defines f(x) to be the sum of the squares of the decimal digits of  the positive integer x, then  x  is happy if for some positive integer n we have (f@@n)(x) = 1.  

For example, 

f(7) = 7^2=49,  
f(49) = 4^2+9^2=97,  
f(97) = 9^2+7^2=130,  
f(130) = 1^2+3^2+0^2 = 10,
f(10) = 1^2+0^2 = 1. 

So 7 is happy.

The first few happy numbers are 

1,7,10,13,19,23,28,31,32,44,49,68,70,79,82,86,91,94,97,100.

 --else returns false. Find the first 50 such happy numbers. Print them out in a sequence. 

Hints:  Note that convert(x,base,10) will give you the decimal digits of x in a list. It should help if you first write a procedure to compute f(x) for any positive integer x.
